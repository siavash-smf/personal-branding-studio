# استودیوی محتوا

**فارسی** · [English](README.en.md)

استودیوی تولید محتوای اینستاگرام برای برند شخصی‌ات، روی کامپیوتر خودت. برای دانشجوهای دوره‌ی پرسنال برندینگ.

از ایده تا متن ریلز، استوری، کاروسل، تدوین ویدیو با زیرنویس فارسی و تحلیل آمار پیج، همه در یک جا. همه‌ی بخش‌ها اول «هسته‌ی برند» تو را می‌خوانند، پس خروجی‌ها با لحن، مخاطب و خط قرمزهای خودت ساخته می‌شوند.

- **روی کامپیوتر خودت اجرا می‌شود.** داده‌هایت (هسته‌ی برند، ایده‌ها، ویدیوها) همین‌جا می‌مانند و جایی آپلود نمی‌شوند.
- **هوش مصنوعی با اشتراک Claude خودت کار می‌کند** (Claude Code). کلید API و پرداخت جداگانه لازم نیست.
- **رایگان و متن‌باز.**

## بخش‌ها

| تب | کار |
|---|---|
| **شروع** | قدم‌های راه‌اندازی، پیشرفتت و روال پیشنهادی هر هفته |
| **داشبورد** | نمای کلی، قدم بعدی، و ترجمه‌ی سریع از لینک یوتیوب |
| **هسته‌ی برند** | پرسش‌نامه درباره‌ی خودت، مخاطب، لحن، پیلرها، رنگ و لوگو. همه‌ی بخش‌های هوشمند قبل از هر کاری این را می‌خوانند |
| **مشاور** | گفت‌وگو با یک مشاور برند شخصی که هسته‌ی برند و ایده‌هایت را می‌داند؛ با صدا و میکروفون |
| **بانک ایده** | ایده را با متن، لینک، ویس یا فایل ثبت کن؛ تحلیل، جستجوی وب و ساخت ریلز با شش هوک، کپشن و هشتگ |
| **ترجمه‌های یوتیوب** | ترجمه‌ی کامل فارسی ویدیوهای انگلیسی برای خواندن، و فرستادن تکه‌های خوب به بانک ایده |
| **استودیو ریلز** | از لینک یوتیوب تا ایده‌ی ریلز و متن آماده‌ی ضبط، با تله‌پرامپتر |
| **تدوین ویدیو** | برش سکوت و تپق، زیرنویس فارسی کلمه‌به‌کلمه، گرافیک، کاور و کپشن (فعلاً فقط مک) |
| **استوری** | متن ← تصویر ۱۰۸۰×۱۹۲۰ با رنگ و لوگوی برندت |
| **کاروسل و پست** | پست چنداسلایدی، دستی یا با Claude |
| **تحلیل اینستاگرام** | آمار پست‌ها، ریل‌ها، استوری‌ها و مخاطب، به‌علاوه‌ی تحلیلگر (اختیاری) |
| **تنظیمات** | پروفایل، مدل Claude هر کار، کلید Gemini |

انتشار دستی است: خروجی‌ها را دانلود می‌کنی و خودت در اینستاگرام منتشر می‌کنی.

## چه چیزهایی لازم داری

- **مک** (macOS 13 یا بالاتر) یا **ویندوز ۱۰/۱۱**
- **اشتراک Claude Pro یا Max** ([claude.ai](https://claude.ai)). همه‌ی بخش‌های هوشمند با همین کار می‌کنند.
- **کلید رایگان Gemini** (پیشنهادی؛ برای ویس، صدای مشاور، ساختن تصویر و متن ویدیو). در صفحه‌ی «شروع» می‌گوید از کجا بگیری.
- اینترنت برای بخش‌های هوشمند. بقیه‌ی استودیو بدون اینترنت هم باز می‌شود.

## نصب روی مک

1. **Terminal** را باز کن: `Cmd + Space` را بزن، بنویس Terminal و Enter.
2. این خط را کامل کپی کن، در Terminal بچسبان و Enter بزن:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/siavash-smf/personal-branding-studio/main/install-mac.sh | bash
   ```

   اگر رمز مک را خواست، تایپش کن و Enter بزن (موقع تایپ چیزی نشان داده نمی‌شود؛ عادی است). نصب بار اول ۵ تا ۱۵ دقیقه طول می‌کشد.
3. وقتی تمام شد، در همان Terminal بنویس `claude` و Enter بزن. با حساب Claude وارد شو، بعد بنویس `/exit`.
4. روی دسکتاپ **Content Studio** را دوبار کلیک کن. اگر مک گفت باز نمی‌شود: راست‌کلیک ← Open ← Open.

استودیو در مرورگر باز می‌شود (`http://127.0.0.1:7788`). پنجره‌ی Terminal کنارش را تا وقتی کار می‌کنی باز نگه دار.

**تدوین ویدیو (اختیاری):** حدود ۴۰۰ مگابایت دانلود دارد و Google Chrome را هم نصب می‌کند:

```bash
~/content-studio/install-video-mac.sh
```

## نصب روی ویندوز

1. **PowerShell** را باز کن: دکمه‌ی Start، بنویس PowerShell و Enter.
2. این خط را کامل کپی کن، در PowerShell بچسبان (راست‌کلیک) و Enter بزن:

   ```powershell
   irm https://raw.githubusercontent.com/siavash-smf/personal-branding-studio/main/install-windows.ps1 | iex
   ```

   اگر ویندوز برای نصب برنامه‌ها اجازه خواست، Yes را بزن.
3. وقتی تمام شد، پنجره را ببند و یک PowerShell **تازه** باز کن. بنویس `claude` و Enter بزن، با حساب Claude وارد شو، بعد بنویس `/exit`.
4. روی دسکتاپ **Content Studio** را دوبار کلیک کن.

پنجره‌ی سیاهی که کنار مرورگر باز می‌شود خود استودیوست؛ تا وقتی کار می‌کنی بازش بگذار. تب «تدوین ویدیو» فعلاً روی ویندوز نیست.

## اولین بار

استودیو با صفحه‌ی **شروع** باز می‌شود و قدم‌به‌قدم جلو می‌بردت:

1. بررسی ابزارها و آزمایش Claude
2. معرفی خودت (اسم، آیدی اینستاگرام، کارت)
3. کلید Gemini
4. هسته‌ی برند: دست‌کم ۱۲ سؤال ضروری
5. اولین ایده در بانک ایده
6. اولین ریلز با «⚡ ساخت کامل»
7. اولین استوری

بالای هر تب هم یک راهنمای کوتاه هست که می‌گوید آن بخش چه کار می‌کند و چطور با آن کار کنی.

## سهمیه‌ی Claude

هر کار هوشمند از سهمیه‌ی اشتراک Claude خودت خرج می‌کند. پیش‌فرض همه‌ی کارها **Sonnet 5.5** است که سریع است و سهمیه را دیرتر تمام می‌کند. در «تنظیمات» می‌توانی هر کار را روی **Opus 5.5** بگذاری؛ دقیق‌تر است ولی روی اشتراک Pro سهمیه را زود تمام می‌کند. اگر به سقف خوردی، چند ساعت صبر کن یا کارها را روی Sonnet بگذار.

## به‌روزرسانی

نسخه‌ی تازه که آمد:

- **مک:** در پوشه‌ی `content-studio` (در پوشه‌ی خانه‌ات) روی `update-mac.command` دوبار کلیک کن.
- **ویندوز:** در پوشه‌ی `content-studio` روی `update-windows.bat` دوبار کلیک کن.

بعد استودیو را ببند و دوباره باز کن. به‌روزرسانی به داده‌هایت دست نمی‌زند.

## داده‌ها و پشتیبان

همه‌ی داده‌هایت داخل پوشه‌ی استودیو (`~/content-studio` در مک، `C:\Users\<اسمت>\content-studio` در ویندوز) است:

- `brand/`: هسته‌ی برند، لوگو و تصویرها
- `data/`: ایده‌ها، ریلزها، گفت‌وگوهای مشاور، کاروسل‌ها، استوری‌ها، ویدیوها و آمار اینستاگرام
- `modules/reels/output/`: ترجمه‌ها و خروجی‌های استودیو ریلز
- `.env`: کلید Gemini و توکن اینستاگرام (برای کسی نفرستش)

برای پشتیبان‌گیری، `brand` و `data` را جایی کپی کن.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| صفحه‌ی استودیو باز نمی‌شود | پنجره‌ی Terminal یا پنجره‌ی سیاه استودیو باید باز باشد. دوباره روی Content Studio دوبار کلیک کن، یا در مرورگر `http://127.0.0.1:7788` را باز کن. |
| Claude جواب نمی‌دهد | در صفحه‌ی «شروع» دکمه‌ی «آزمایش Claude» را بزن. اگر ورود نخورده‌ای، در Terminal یا PowerShell بنویس `claude` و وارد شو. اگر پیام سهمیه آمد، چند ساعت صبر کن یا در «تنظیمات» کارها را روی Sonnet بگذار. |
| زیرنویس یوتیوب گرفته نشد | ویدیو باید زیرنویس داشته باشد. اگر داشت، yt-dlp را به‌روز کن: اسکریپت به‌روزرسانی را اجرا کن. |
| ویس یا صدای مشاور کار نمی‌کند | کلید Gemini را در «تنظیمات» بگذار. ویس حداکثر حدود ۵ تا ۸ دقیقه است. |
| ساختن تصویر کاروسل خطا می‌دهد | ساختن تصویر روی بعضی کلیدهای رایگان Gemini بسته است؛ در Google AI Studio صورت‌حساب (Billing) را فعال کن، یا عکس خودت را آپلود کن. |
| مک می‌گوید Content Studio باز نمی‌شود | راست‌کلیک ← Open ← Open (فقط بار اول). |

## شخصی‌سازی استودیو با Claude Code

این استودیو مال خودت است. هر چیزی را که بخواهی می‌توانی عوض کنی یا اضافه کنی، بدون اینکه منتظر نسخه‌ی تازه بمانی. کد ساده است (پایتون بدون هیچ وابستگی، جاوااسکریپت بدون فریم‌ورک) و Claude Code راهنمای ساختارش را در [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) پیدا می‌کند.

1. Terminal (مک) یا PowerShell (ویندوز) را باز کن و برو داخل پوشه‌ی استودیو:
   - مک: `cd ~/content-studio`
   - ویندوز: `cd $HOME\content-studio`
2. بنویس `claude` و Enter بزن.
3. چیزی را که می‌خواهی به فارسی بگو. چند نمونه:
   - «یه تب تازه بساز برای تقویم محتوای هفتگی که ایده‌های بانک ایده رو روی روزهای هفته بچینم»
   - «به‌جای شش هوک، ده تا هوک بساز»
   - «به ویرایشگر ریلز یه بخش "متن روی تصویر" اضافه کن»
   - «رنگ‌های خود استودیو رو روشن کن»
4. وقتی تمام شد: اگر Claude فایل‌های پایتون (`.py`) را عوض کرده، پنجره‌ی استودیو را ببند و دوباره باز کن. برای بقیه‌ی تغییرها کافی است صفحه‌ی مرورگر را refresh کنی.

چند نکته:

- **قبل و بعد از هر تغییر بزرگ بگو «تغییرها رو با git ذخیره کن».** اگر چیزی خراب شد، کافی است بگویی «برگرد به نسخه‌ی قبل».
- **داده‌هایت امن‌اند.** پوشه‌های `brand` و `data` و فایل `.env` جزو کد نیستند و با تغییر کد پاک نمی‌شوند.
- **قواعد محتوا را در «هسته‌ی برند» بنویس، نه در کد.** لحن، خط قرمزها و CTA همان‌جا جایشان است. فایل `CLAUDE.md` ریشه را هم برای یادداشت‌های برنامه‌نویسی استفاده نکن؛ ایجنت‌های تولید محتوای استودیو آن را می‌خوانند.
- **شخصی‌سازی از سهمیه‌ی Claude خودت خرج می‌کند.** کارهای بزرگ را روی اشتراک Pro چند بخش کن.

### گرفتن نسخه‌ی تازه بعد از شخصی‌سازی

اگر کد را عوض کرده باشی، اسکریپت به‌روزرسانی ممکن است نتواند تغییرهای تو و نسخه‌ی تازه را خودش با هم جمع کند و پیام بدهد. آن وقت در Claude Code همان پوشه بنویس:

> آخرین نسخه‌ی استودیو رو از گیت‌هاب بگیر و با تغییرات من ادغام کن.

Claude تغییرهایت را نگه می‌دارد و فقط چیزهای تازه را اضافه می‌کند. اگر نخواهی، اصلاً لازم نیست به‌روزرسانی بگیری؛ نسخه‌ی خودت همان‌طور کار می‌کند.
